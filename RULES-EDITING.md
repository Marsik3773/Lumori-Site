# Как менять правила Lumori

Весь текст правил находится в **`rules.md`** в корне проекта. Это отдельный
файл настроек содержания: редактировать HTML, CSS или JavaScript не требуется.
Формулировки и наказания сайт берёт из этого файла без изменений.

## С телефона через GitHub

1. Открой репозиторий `Marsik3773/Lumori-Site` и файл `rules.md`.
2. Нажми значок карандаша (Edit). Если его не видно, открой меню файла.
3. Измени нужный текст, сохрани номера пунктов или добавь новые.
4. Нажми **Commit changes** и сохрани изменения в основной ветке сайта.
5. Дождись успешного выполнения **Actions → Publish site**. После публикации
   обнови страницу сайта. Если создавал отдельную ветку, сначала объедини её
   с основной через Pull Request.

## Формат файла

```md
# Правила сервера Lumori

Вступительный текст.

## 1. Общие положения

### 1.1. Название пункта
Текст правила. Новый абзац отделяется пустой строкой.

**Наказание:** Текст наказания.

### 1.2. Другой пункт
Запрещены:
- первый пункт списка;
- второй пункт списка.

Команда записывается так: `/shop`.
```

Поддерживаются заголовки `##` и `###`, обычные абзацы, списки с `- ` или `* `,
**жирный текст** между `**` и команды между обратными кавычками.
Единственный заголовок `#` служит названием исходного документа: на странице
уже есть заголовок «Свод правил». Нумерация задаётся вручную.
HTML, таблицы, вложенные списки и другие расширения Markdown не поддерживаются.

## Как это работает

GitHub Pages автоматически формирует раздел правил из `rules.md` при каждой
публикации. Текст в `index.html` между маркерами `RULES:START` и `RULES:END`
генерируется автоматически: его не нужно редактировать вручную.
Правила находятся в готовом HTML и не требуют отдельной загрузки или JavaScript.
Остальные части страницы и оформление сохраняются.

Для локальной проверки или размещения файлов вручную сначала выполни из корня
проекта (требуется Node.js):

```sh
node scripts/render-rules.mjs
```

Затем открой `index.html`. Для Netlify генерация уже задана в `netlify.toml`.
